### Fixed
- A new business is no longer offered things it can't use yet. With no clients, Home's empty day now offers Add Client instead of New Route and Schedule Visit, since a route or a visit has nobody to be for. Schedule Visit with no clients now says so and offers Add Client right there.
- Searching your clients and finding nobody now says "No clients match" and names what you searched for, instead of showing only the totals above an empty list.
- Importing clients from a spreadsheet is a Pro tool, but the empty Clients screen and the Get Started card offered it with no sign of that. They now carry the Pro mark when you're not on Pro, so the upgrade screen is no surprise.

### Changed
- The Clients filter that showed only clients with visits was called "Active", which clashed with the Inactive section below it. It is now called "Has Visits". It selects the same clients as before.
