### Changed
- New Client now asks whether this is an Existing Customer or a New Lead. Everyone typed in by hand used to be called a lead, even regular customers, because only the spreadsheet import marked anyone as a customer. Existing Customer is the default, except when you add someone from Documents to quote them: there it starts on New Lead, so they show as Quoted and you get the follow-up reminder.
- Only a name is needed to save a client. A phone number is optional, so a client with no number can be saved, edited and saved again. Texting and calling were checked: the "text the next client" offer on a route no longer appears for a stop with no number.
- New Client has a Notes field, so a gate code no longer has to wait for the client's page.
- Cancel on New Client asks before throwing away what you typed, as Edit Client does. Swiping the form down while it has text is blocked rather than discarding it.
