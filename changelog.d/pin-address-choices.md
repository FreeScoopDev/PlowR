### Changed
- **Adjust Pin suggests the address it finds instead of taking it.** After you move the pin, the address the map finds there is shown with "Use This Address"; the client's address changes only if you tap it, and it's offered only when it's a different address, not the same one written another way. It used to be replaced on every move, often by a reformatted version of the same address or a neighbour's number. A new address typed on the client's page before moving the pin is kept, and saved with the moved pin.
- **When a changed address can't be found, a client who has a pin keeps it or gets the address typed again.** The prompt offers "Keep Current Pin" (the new address with the client's pin, which Adjust Pin can move) or "Edit Address". A client with no pin is still offered "Save Without Pin". The same choice is offered when the map couldn't be reached, alongside Try Again.
