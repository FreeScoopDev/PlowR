### Internal
- A CSV reader for Import Clients (`CSVReader`), with no third-party code: UTF-8 with or without a byte-order mark, UTF-16 with one, otherwise Windows Latin-1 (what Excel on Windows writes), read byte by byte so a text file always reads (its five undefined bytes become a visible �); comma, semicolon or tab, whichever the header line uses (blank lines before it skipped), or as Excel's "sep=" line says; spaces after a closing quote kept when more text follows; only CR and LF end a line; an unclosed quote reported with its line; quoted fields with separators, line breaks and doubled quotes; any line ending; blank rows dropped and short rows padded; and the apostrophe CSVExport and spreadsheets put before formula-like text taken off. An .xlsx or .numbers file is recognized and refused, rather than read as garbage. PlowR's own export reads back as it went out, apart from spaces and line breaks around a field, which an import trims.
