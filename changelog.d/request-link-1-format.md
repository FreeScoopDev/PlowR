### Internal
- The Request Service link's format (`RequestLink`), groundwork for a link a business can share so prospects can ask for service without an app or a server. A business's link (getplowr.app/r/) carries only what's public: name, phone, optional email, the services offered and a welcome line. The **Add to PlowR** link in a request (getplowr.app/lead/, or the app's own plowr://lead) carries what the prospect typed. Everything goes after the `#`, which browsers never send to a server, so the website never sees anyone's details. Anyone can make such a link, so what one carries is treated as untrusted: cut to size, cleaned of control characters, and refused without a name and a phone number to call back.
