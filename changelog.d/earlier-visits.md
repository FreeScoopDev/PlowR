### Added
- Visits marked complete without a Service Log record now appear in each client's Service History, so it starts with the work already done instead of empty. That covers visits completed before the log existed, and visits completed on a device still running an older PlowR. They're labelled **Billing Not Tracked** and never counted in "Not Billed Yet": PlowR can only tell such work was billed if the invoice was made from the visit (Schedule → Invoice). Those show as Invoiced, including once the invoice arrives from iCloud later. Each is dated when the visit was due (or completed, if that was earlier), with the visit's expected services at today's catalog prices, because the prices at the time weren't kept. Route runs from before can't be recovered: each run used to wipe the one before.

### Internal
- `ServiceLog.backfillAll` runs after each launch on a `ModelContext` of its own, in passes (`backfillCompletedVisits`, up to `backfillBatch` = 200 visits each, then a save), giving the main thread back between passes. A launch cut short keeps what's done. It only looks at completed visits without the synced `serviceLogged` mark, so each visit is copied once, on whichever device gets there first, and a job the user deleted is never remade. A visit waits until its client is on the device. With nothing to do, a pass fetches nothing beyond the visits and clients.
- `ServiceLog.linkEarlierVisits` runs after each iCloud import. It gives a copied-in job its visit's invoice, and its services if the catalog hadn't arrived when it was copied.
- A new record source, `.beforeLog`, is a new value in an existing field: no CloudKit schema change. `ServiceLog.billingStatus` is the one rule for a job's label (Invoiced, Billing Not Tracked, No Charge, Not Billed), and `isUnbilled` is defined by it. In a merge, a tracked copy's source wins over `.beforeLog`, so which device was quicker doesn't decide whether work is owed.
- Completing a visit and copying one in fill a record through one function (`fill`), so the two can't differ.
